# 동민이의 핸드폰

정적 웹사이트입니다. index.html을 저장소 최상위에 올리고 GitHub Pages로 배포하세요.

## 수정 위치
- js/phone.js: 잠금화면, 홈, 아이콘, 초기화
- js/apps.js: 앱 화면, 기본 대화 데이터, 과거 대화, 음원 로딩
- js/conversation.js: 인물별 규칙형 답장, 전화 이벤트, 메모 이벤트, 배터리, 음악 화면
- css/style.css: 화면 스타일. 음악 화면은 맨 아래 Music player 항목
- assets/images/: 배경화면, 프로필, 앨범 이미지

대화·읽음 상태는 새로고침하면 초기화됩니다. 자동 답장은 지정된 다섯 명만 지원합니다.
음원은 제공되지 않습니다. 음악 화면에서 파일을 선택하면 재생할 수 있습니다.
등록곡은 한 곡이므로 이전·다음 버튼은 현재 곡의 처음으로 이동합니다.
전화는 실제 통화가 아닌 화면 시뮬레이션입니다.
